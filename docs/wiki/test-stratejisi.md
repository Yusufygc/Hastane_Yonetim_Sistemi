# Test Stratejisi

Kaynak: `plan.md` §11. Faz bağlantısı: [[faz-plani]].

| Katman | Araç | Kapsam |
|---|---|---|
| Unit | xUnit, AwesomeAssertions | State geçişleri, slot üretimi (pencere × çalışma saati × izin), snapshot, iptal süresi, doktor-hizmet onayı ([[randevu-kurallari]]) |
| Entegrasyon | Gerçek PostgreSQL (compose / CI service; geçici DB) | Exclusion constraint, EF eşlemeleri, outbox |
| Eşzamanlılık | Gerçek PostgreSQL | N paralel istek aynı slota → **tam 1 başarılı, N-1 `409`** |
| Mimari | NetArchTest | Katman/feature kuralları ([[mimari]]) |
| API / Yetki | `WebApplicationFactory` | Endpoint tarama, rol×uç matrisi, IDOR, JWT doğrulama (bozuk/sahte/süresi dolmuş token), refresh rotation ([[kimlik-ve-yetki]]) |

## Zorunlu çakışma senaryoları
Birebir aynı aralık; kısmi kesişim (baş/son/içinde/kapsayan); bitişik aralıklar (çakışmaz); farklı doktor aynı saat (çakışmaz); iptal/red sonrası slot yeniden alınabilir; aynı hasta iki doktorda aynı saat; DST geçiş günü; gün sonu (23:xx); uygunluk dışı / izin günü / hastane kapalı saat; `PENDING` doktor-hizmetiyle randevu talebi (reddedilmeli).

## Çalıştırma
- Hızlı döngü: `dotnet test Hospital.sln` (Windows'ta Smart App Control kendi DLL'inizi bazen engeller — bkz. [[docker-ortam]]).
- Güvenilir yol: `./scripts/test-docker.ps1` — derleme + testler Linux .NET 9 SDK container'ında; PostgreSQL için `host.docker.internal:5432`.
- Faz 5 sonrası: **275 birim, 9 mimari, 279 entegrasyon** (birim: `EmailOutboxMessageTests` durum/geri çekilme/`FAILED`, `NotificationHandlerTests` alıcı seçimi + dedup + şablon; entegrasyon: `NotificationOutboxTests` olay→satır, **atomiklik (DB çakışmasıyla geri alınan randevunun e-postası da yok)**, 20 paralel talep → 1 doktor e-postası, dedup, gönderim/yeniden deneme/geri çekilme/vazgeçme, **4 işleyici paralel → çift gönderim yok**, `NotificationBackgroundTests` arka plan işleyici + SMTP kesinti/kurtarma, `MailpitDeliveryTests` **gerçek SMTP → Mailpit API doğrulaması**, `SmtpUnavailableTests` gerçek kapalı port). Önceki satır — Faz 4 sonrası: **251 birim, 9 mimari, 260 entegrasyon** (birim: `SlotCalculatorTests` ızgara/kesişim/izin/dolu/hazırlık/ufuk/geçerlilik + **DST** ileri geçiş ve 23/25 saatlik gün, `AppointmentStateTests` 20 geçiş×durum tablosu, `AppointmentTests` snapshot/olay/neden/süre sınırı, `Faz4ValidatorTests`; entegrasyon: `AppointmentSlotTests` anonim slot ucu, `AppointmentFlowTests` yaşam döngüsü + sahiplik/IDOR + kapsam + listeler + snapshot, `AppointmentConcurrencyTests` **HTTP'de 20 paralel talep → 1 × 201, 19 × 409**, çift onay/red ve çift iptal yarışları, `AppointmentGuardTests` gelecek-randevu denetimleri; `AppointmentOverlapConstraintTests` gerçek FK'li doktorla DB kısıtları). Önceki satır — Faz 3 sonrası: **162 birim, 9 mimari, 215 entegrasyon** (birim: `DoctorTests` talep/onay/atama + uygunluk çakışma/saat/dönem + izin, `StaffAndProfileTests`, `Faz3ValidatorTests`; entegrasyon: `DoctorManagementTests` hesap/kapsam/rol, `DoctorServiceFlowTests` talep→onay→katalog ve kapsam, `DoctorScheduleTests` uygunluk/izin + **DB exclusion constraint'lerinin ham SQL ile doğrudan sınanması (23P01)**, `AccountAndProfileTests` profil/parola/personel/yönetici/pasifleştirme). Önceki satır — hata yönetimi sonrası: 104 birim, 9 mimari, 156 entegrasyon (`RequestErrorTests`: gövde/parametre/JSON/içerik türü hataları, 401-405-415-429 gövdeleri, 422/500, Development ve Production ortamı; `RequestErrorTranslatorTests`: saf çevirici). Önceki satır — JWT geçişi sonrası: 104 birim, 9 mimari, 113 entegrasyon (JWT: imza/süre/issuer/audience/stamp reddi, refresh rotation + reuse detection, logout, CSRF yok). Faz 2 sonu (cookie dönemi): 81 birim, 9 mimari (DI kuralı dahil, [[di-kurallari]]), 91 entegrasyon testi (kayıt, giriş, kilitleme, CSRF, oturum iptali, rol 403, hız sınırı, TPT; çakışma kısıtları ve 20 paralel istek — [[randevu-kurallari]]; şube/bölüm/hizmet CRUD, çalışma saati eşitleme, **şube yöneticisi kapsam ihlalleri → 404**, anonim katalog, organizasyon).
- Test yardımcıları: `AdminSessions` (seed'li süper yönetici girişi, DB'ye şube yöneticisi yazma), `TestAdmin` (yalnız test değerleri), `ApiClient.PutAsync/DeleteAsync/SendAsync/LoginAsync`; Faz 3: `AdminSessions.CreateDoctorAsync/AddAvailabilityAsync/LoginAsync`, `TestDoctor` (seed örnek doktor + ortak parola); Faz 4: `AppointmentKit` (şube + doktor + onaylı hizmet + Pazartesi 09-12 uygunluk hazır senaryosu `BookingSetup`, slot/randevu yardımcıları, `MoveToPastAsync` ile başlamış randevu). Gerçek saat kullanılır (sahte saat JWT'yi bozardı); uzak tarih ve `Appointment:*` ayarlarının fabrika üzerinden geçersiz kılınmasıyla süre sınırı sınanır.

Test-only uçlar: `HospitalApiFactory(includeProbeEndpoints: true)` ile `/api/test/*` uçları (rol politikaları, hata üretimi) kaydedilir (randevu probe ucu Faz 4'te kaldırıldı, gerçek uç kullanılır); gerçek uygulamada bulunmaz, endpoint-yetki taramasına girmez.

## Ortam
Entegrasyon testleri `docker compose up -d` ile çalışan PostgreSQL **ve Mailpit** gerektirir ([[docker-ortam]]); Mailpit kapalıysa Mailpit testleri açıklayıcı hata verir. Testcontainers **kullanılmıyor**: Smart App Control imzasız DLL'i engelliyor ([[kararlar]] K-20).
